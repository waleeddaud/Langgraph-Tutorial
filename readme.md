# LangGraph Tutorials

Welcome to the **LangGraph Tutorials** repository! 👋

This repo contains hands-on projects and code snippets built by following along the **CampusX - LangGraph Course**, with a focus on the **AgentAI** section.

---

## 📚 What is LangGraph?

[LangGraph](https://github.com/langchain-ai/langgraph) is a powerful library built on top of LangChain that allows you to create **stateful, multi-node AI workflows** using graphs. It supports agents, memory, streaming, and advanced branching logic.

---

## 🎯 What's Inside?

This repo includes:

-  Step-by-step LangGraph workflows
-  Nodes for blog generation using LLMs
-  Implementation of **AgentAI** patterns
-  Experimentation with LangChain + Gemini / OpenAI
-  Checkpointing and memory in AI pipelines
